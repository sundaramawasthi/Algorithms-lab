# Algorithms Lab

A collection of Data Structures & Algorithms lab experiments in Python.

Every experiment is a small, self-contained script that prompts for its
input and prints the result. Each file starts with a short header that
states the objective and the time / space complexity.

## Requirements

- Python 3

That's it — no third-party packages.

## Run

```bash
python dsa_lab/exp06_insertion_sort.py
```
