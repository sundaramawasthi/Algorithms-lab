# DSA Lab — experiments

Each file here is a self-contained experiment. Run any of them with:

```bash
python exp01_prime_number.py
```

## Index

| Exp | File                        | Objective                                          | Complexity                            |
|-----|-----------------------------|----------------------------------------------------|---------------------------------------|
| 01  | `exp01_prime_number.py`     | Check whether a given number is prime              | Best O(1), Avg/Worst O(√n), O(1)      |
| 02  | `exp02_max_min_array.py`    | Find maximum and minimum of an array               | O(n), O(1)                            |
| 03  | `exp03_linear_search.py`    | Linear search                                      | Best O(1), Avg/Worst O(n), O(1)       |
| 04  | `exp04_single_loop.py`      | Complexity of a single loop                        | O(n), O(1)                            |
| 05  | `exp05_nested_loop.py`      | Complexity of a nested loop                        | O(n²), O(1)                           |
| 06  | `exp06_insertion_sort.py`   | Insertion sort                                     | Best O(n), Avg/Worst O(n²), O(1)      |
| 07  | `exp07_bubble_sort.py`      | Bubble sort with early exit                        | Best O(n), Avg/Worst O(n²), O(1)      |
| 08  | `exp08_counting_sort.py`    | Counting sort (linear, non-negative integers)      | O(n+k), O(n+k)                        |
| 09  | `exp09_selection_sort.py`   | Selection sort                                     | O(n²), O(1)                           |
| 10  | `exp10_triangle_loop.py`    | Multiplication triangle via nested loops           | O(n²), O(1)                           |
| 11  | `exp11_merge_sort.py`       | Merge sort                                         | O(n log n), O(n)                      |
| 12  | `exp12_quick_sort.py`       | Quick sort                                         | Best/Avg O(n log n), Worst O(n²), O(log n) |
